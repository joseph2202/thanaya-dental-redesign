# قاعدة البيانات المحلية

المخطط الحالي في `schema.prisma` يستخدم Prisma مع SQLite. ملف `dev.db` محلي ومستثنى من GitHub، لذلك تنزيل المستودع لأول مرة لا يتضمن منتجات أو مستخدمين أو طلبات.

من مجلد `backend`، بعد تثبيت الحزم وضبط `DATABASE_URL="file:./dev.db"` في `.env`، أنشئ قاعدة تطوير جديدة:

```bash
touch prisma/dev.db
npm run db:push
```

`db:push` يطبّق المخطط الحالي ويولّد Prisma Client. لا تشغّله على قاعدة تحتوي بيانات مهمة بعد تعديل المخطط قبل أخذ نسخة احتياطية ومراجعة الأثر. لا توجد ملفات migrations رسمية في هذا المشروع حالياً؛ يلزم إعداد مسار ترحيل ونسخ احتياطي قبل النشر.
