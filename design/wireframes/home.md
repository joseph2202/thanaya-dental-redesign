# الصفحة الرئيسية - معتمدة

الترتيب:
1. شريط علوي رفيع: لغة + عملة + رقم تواصل
2. هيدر: شعار ثنايا + بحث كبير + حساب + سلة
3. شريط تصنيفات رئيسية
4. بانر رئيسي: رسالة ثقة + زر تسوق الآن
5. بطاقات تصنيفات سريعة
6. منتجات مميزة (شبكة)
7. شريط ثقة: أصلية / شحن عراق / دفع عند الاستلام / دعم
8. الأكثر مبيعًا
9. الماركات
10. فوتر كامل
