# ثنايا — معاينة المتجر الفعلية بصورة معزولة وآمنة

## الهدف
تشغيل متجر ثنايا الحقيقي (Next.js + Express + Prisma) مع بيانات صناعية واضحة داخل Chrome على الماك، بدون لمس قاعدة `backend/prisma/dev.db` أو `backend/uploads` أو فرع المشروع الذي يشتغل عليه المالك.

هذه معاينة تطوير محلية، **ليست إطلاقاً للموقع أو منصة دفع فعلي**. اختر أحدث فرع `feature/erp6-expenses-cash-20261102` بعد نجاح CI.

## الخطوات على الماك
من Terminal افتح نسخة منفصلة تماماً، ولا تحوّل فرع مجلدك الأصلي:

```bash
cd ~/Documents
git clone --branch feature/erp6-expenses-cash-20261102 --single-branch \
  https://github.com/joseph2202/thanaya-dental-redesign.git thanaya-preview
cd thanaya-preview
bash scripts/preview-local.sh
```

السكربت نفسه ينزّل مكتبات النسخة التجريبية فقط، ينشئ `/tmp/.../thanaya-preview-*/preview.sqlite`، يولّد سر جلسة مؤقت، ويملأ نموذجاً محدوداً من المنتجات والطلبات والموردين والفواتير والتكلفة والمصاريف، ثم يشغّل:
- الواجهة: http://127.0.0.1:3108
- دخول الإدارة: http://127.0.0.1:3108/login
- تقارير الطلبات والـ COGS: http://127.0.0.1:3108/admin/reports
- الموردون والذمم: http://127.0.0.1:3108/admin/payables
- المصاريف والصندوق: http://127.0.0.1:3108/admin/cash
- استلام البضاعة: http://127.0.0.1:3108/admin/receiving

السكربت يطبع **البريد وكلمة مرور مالك تجريبي عشوائية** داخل Terminal عند كل تشغيل. استعملها فقط في نسخة المعاينة ولا تنسخها لقاعدة المتجر الحقيقية.

إذا كانت بورتات 3108 أو 4108 مشغولة سيقف بدون إغلاق أي عملية سابقة. السكربت يوقف الخادمين اللي شغّلهم وحده ويزيل قاعدة بياناته المؤقتة عند ضغط Ctrl+C. **لا تشغّل `prisma db push` يدوياً**.

## ملاحظات مهمة
- الصفحة التي تراها فعلية من مشروع ثنايا مع بيانات صناعية وليست صورة تصميم أو محاكاة.
- الدفع الإلكتروني الفعلي غير مفعل. خيار الدفع بالبطاقة غير قابل للإتمام حتى الاتفاق مع مزود دفع معتمد والتجربة عبر Hosted Checkout وWebhooks.
- ERP05 margin يعرض فقط هامش البضاعة لحالات تكلفة معروفة دون مرتجعات، وليس صافي ربح مؤكد.
- ERP06 الصندوق يعرض صافي حركة النقد المدخلة للسجلات، وليس جرد الصندوق الفعلي.
- تحديث مشروعك الأصلي، اعتماد الجداول وترحيل البيانات يحتاج لاحقاً نسخ احتياطية مستقلة وشرط أمان؛ هذه المعاينة لا تقوم بأي ترحيل حقيقي.
