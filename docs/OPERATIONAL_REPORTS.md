# مؤشرات الإدارة التشغيلية

`GET /api/reports/operations?range=7|30|90|all` للمالك والإدارة فقط، وno-store. مصدر الأرقام في PR #66 اجتاز CI #242. الدفعة 12 تربطه مع `/reports/costs` بلوحة التحكم، وتوضح نطاق الفترة مقابل الذمم والصلاحية الحالية. لا مخطط جديد أو كتابة، ولا دفتر أستاذ عام أو ميزانية أو أرباح صافية محسوبة.

| المؤشر | المعنى والنطاق |
| --- | --- |
| التحصيل/الاسترداد | حركات OrderPaymentEvent الموثقة من الموظفين خلال الفترة بحسب تاريخ الحركة، لا تاريخ إنشاء الطلب أو رجوع المتصفح |
| المصاريف | StoreExpense المسجلة خلال الفترة بجميع طرق السداد، دون إعادة عد مشتريات الموردين |
| صافي حركة النقد | نقد الزبائن ومساهمات المالك، ناقص النقد المسترد ونقد الموردين والمصاريف النقدية وسحوبات المالك؛ ليس رصيد الصندوق أو الربح |
| متبقٍ للتحصيل | إجمالي طلبات حالتها مسلّم ولا يوجد لها مرتجع، ناقص كل تحصيلاتها المسجلة، لكل الفترات؛ قد تشمل طلبات قديمة مجهولة التكلفة |
| مستثنى بسبب المرتجع | طلبات مسلّمة ذات أي مرتجع تستبعد من المبلغ أعلاه حتى تسوية الاعتراف بالإيراد/المرتجع. حالتها وعدد المستثنى لا يخفيان |
| مستحقات الموردين | فواتير مسجلة ناقص كل تسديداتها، لكل الفترات؛ لا ينشأ الدين من أمر شراء/استلام وحده |
| المتأخر للموردين | المتبقي من فواتير تاريخ استحقاقها قبل اليوم العراقي؛ غير المسدد منها فقط |
| صلاحية التشغيلات | الوضع الحالي لكل تشغيلات ذات مخزون موجب، المنتهي قبل اليوم، والقريب من اليوم إلى 30 يوماً. قائمة أول 8 مع counts كاملة وhasMore |

يرفض التقرير السجلات غير المتناسقة (تحصيل أكبر من الطلب/استرداد أكبر من المحصل/سداد مورد أكبر من الفاتورة/قيم تالفة)، بدلاً من إظهار رقم محتمل. المجاميع تتحقق من الأعداد الصحيحة الآمنة. الديون والتنبيهات الحالية لا تتغير بمجرد تضييق الفترة؛ مصاريف وحركات الفترة تتغير.

قراءة واحدة داخل transaction مع queries ذات parameters مرتبطة. لا raw SQL من المستخدم. هامش البضاعة يبقى في `/reports/costs` بتغطية التكلفة واستثناء المرتجعات، ولا نطرحه تلقائياً من مصاريف فترة مختلفة لنصنع ربحاً صافياً. `netProfitIqd` و`actualCashBalanceIqd` يظلان null.

التحقق: `backend: npm run test:operations` (build + 9 فحوص API صناعية). يشمل استرداداً فعلياً ضمن fixture بعد مرتجع جزئي، تاريخ تحصيل قديم مقابل مصروف حديث، مخزون منتهٍ/صالح اليوم/بعد 30 يوماً، pagination التنبيه، رفض سجلات تالفة وصلاحيات السيرفر، وbytes قاعدة المتجر وWAL ثابتة عند القراءة.

واجهة FinancialDashboard تلغي طلبات الفترة السابقة وتخفي أرقامها عند التحميل والفشل، وتسمح بإعادة المحاولة. فحص Chrome لأرقام الفواتير والمصاريف وتأخر/فشل استجابة الفترة و390/768px اجتاز CI #243، PR #67. صور المراجعة قرئت. لا تستعمل أرقام الشبكة الصناعية في screenshots النهائية؛ تعود للفترة الحقيقية أولاً.
