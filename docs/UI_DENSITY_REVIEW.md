# ثنايا — جولة تقليل الفراغات في الموقع بالكامل

> حالة المراجعة: **تغييرات تصميم في فرع مستقل، لم تُختبر محلياً بعد ولم تُدمج**. لا تغييرات على قاعدة البيانات أو الأسعار أو الطلبات.

## المشاكل التي عالجناها

1. **الفراغ العمودي الإجباري:** إزالة `min-height:55vh` من `.site-main`؛ الصفحة القصيرة تنتهي حسب محتواها، مو حسب ارتفاع مصطنع.
2. **الفوتر:** تقليل `margin-top` على الصفحات الداخلية، وتخفيف الحشوات والفواصل مع إبقاء أقسام الاتصال والروابط.
3. **المقياس العام:** تخفيض ارتفاع `.site-section` والعناوين الرأسية، ورفع الحد الأقصى للحاوية إلى 1360px حتى تستفيد شاشات سطح المكتب العريضة من مساحتها.
4. **الهيدر:** تقليل ارتفاع الشريط الرئيسي والمسافة تحت بحث الموبايل.
5. **الرئيسية:** تقليل المسافات في البطل (Hero)، أقسام المنتجات، رحلة التسوق، البانر، وتخفيض ارتفاع بطاقات التصفح.
6. **الكتالوج:** نفس التوزيع المتكيّف إذا قسم واحد أو قسمان في صفحة الأقسام؛ تقليل ارتفاع ترويسة المنتجات وفراغ الحالة الفارغة.
7. **صفحات الشراء:** ضبط فراغات تفاصيل المنتج والسلة وإتمام الطلب والحساب وتفاصيل الطلب.
8. **صفحات الدخول والبحث:** تقليل الهوامش الكبيرة خاصة إذا المحتوى قليل.
9. **الإدارة:** تقليل حشوات AdminLayout والترويسة وقوائم الأوامر؛ تحسين أقسام إدارة المنتجات والطلبات والتقارير والإعدادات والمستخدمين وغيرها.

## ما لم نغيّره

- مقياس أزرار اللمس الأساسي، إذ يلزم أن تبقى سهلة النقر.
- ترتيب بيانات الأعمال، صلاحيات المدير أو الموظف، وطريقة دفع/تأكيد/توصيل الطلبات.
- قاعدة SQLite، جداول Prisma، API، سجلات المخزون، الطلبات، ملفات الصور أو بيانات العملاء.

## فحوصات إلزامية بعد سحب الفرع

**البناء:** `cd frontend && npm run build` (يجب أن تظهر نتيجة TypeScript ناجحة).

**المراجعة البصرية في المتصفح:**
- شاشة 1440px أو أكبر: الرئيسية، المنتجات، الأقسام، تفاصيل منتج، السلة.
- شاشة 390px للموبايل: الهيدر، البحث، بطاقات الأقسام، السلة، إتمام الطلب، زر الشراء.
- حساب الزبون: `/account`، العناوين، تفاصيل طلب وحالاته.
- صفحات الإدارة: `/admin`, `/admin/products`, `/admin/orders`, `/admin/reports`, `/admin/settings`, `/admin/delivery`, `/admin/users`, `/admin/categories`, `/admin/coupons`.
- صفحات قصيرة أو فارغة: السلة الفارغة، نتائج بحث دون نتائج، عروض دون منتجات، إشعارات دون رسائل، صفحة دخول وتسجيل.
- **أهم معايير القبول:** عدم ظهور تمرير أفقي؛ عدم قص أزرار أو جداول أو نص؛ الحقول تبقى مقروءة وقابلة للمس؛ أقل فراغات بدون ازدحام.

## موضوع مؤجل حسب قرار صاحب المشروع

توزيع ومتابعة الطلبات على موظف واحد أو شفتات، زر تواصل واتساب من الطلب، ربط المندوب/شركة التوصيل، وطريقة تأكيد الاستلام من الزبون: **مؤجلة حتى معرفة طريقة التوصيل الفعلية**. التفاصيل والأسئلة التشغيلية في [DELIVERY_WORKFLOW.md](DELIVERY_WORKFLOW.md).
