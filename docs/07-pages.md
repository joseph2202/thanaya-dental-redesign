# صفحات الموقع وترتيب أقسامها

## الرئيسية (من فوق لتحت)
1. شريط علوي: لغة + عملة + تواصل
2. هيدر: شعار + بحث + حساب + سلة
3. شريط التصنيفات
4. بانر رئيسي
5. بطاقات التصنيفات السريعة
6. منتجات مميزة
7. شريط الثقة
8. الأكثر مبيعًا
9. الماركات
10. فوتر

## صفحة المنتجات
- فلاتر جانبية: تصنيف، ماركة، سعر، توفر
- شريط ترتيب: الأحدث، الأرخص، الأغلى، الأعلى مبيعًا
- شبكة 4 أعمدة كمبيوتر / 2 موبايل

## صفحة المنتج
- مسار تنقل
- معرض صور
- اسم، ماركة، تقييم، سعر، توفر
- كمية + إضافة للسلة + شراء الآن
- تبويبات: وصف / مواصفات / تحذيرات / شحن وإرجاع
- منتجات مشابهة

## السلة
- جدول عناصر + كوبون + ملخص جانبي

## الدفع
- 3 خطوات: عنوان → شحن → دفع (عند الاستلام أولًا)
- ملخص جانبي ثابت + صفحة تأكيد برقم طلب
