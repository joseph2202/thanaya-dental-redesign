# ثنايا — البنر قابل للتعديل من لوحة الإدارة

**الحالة:** شغل ضمن فرع تجريبي، يحتاج اختبارات على الماك ونسخة احتياطية قبل تحديث قاعدة البيانات. لا نشر الآن.

## منو يغيّر البنر؟
- **المالك:** من `/admin/settings` → «البنر الإعلاني بالرئيسية». يغيّر عبارة صغيرة وعنواناً ووصفاً ونص الزر ووجهة الزر، ويختار ظهور البنر أو إخفاءه.
- **المصمم (اختياري):** يصمم صورة دعائية. المالك يرفعها ويشوف المعاينة قبل حفظ الإعدادات. الصورة ما تشترط وجود تصميم خاص حتى يعمل البنر.
- **الزبون:** يشوف النسخة المحفوظة بالصفحة الرئيسية؛ ما يحتاج تحديث كود عند تغيير الإعلان.

## ليش ضبطناها بهذا الشكل؟
- يحافظ على الهوية الزرقاء الافتراضية لما ماكو صورة.
- يمنع إضافة روابط زر عشوائية: الخيارات الآمنة المنتجات، التصنيفات، العروض، حسابي.
- صورة البنر تُرفع من نظام الصور الموجود في الباك إند، مع تحقق من النوع والحجم؛ ما ننشر روابط خارجية من حقول الإعدادات.
- الحفظ مقصور على دور **owner**. كل تغيير يُسجّل في سجل StoreSettingsChange ويستخدم revision لمنع ضياع تحديث جهاز آخر.
- لا يغيّر المخزون أو طلبات الزبائن.

## النشر المحلي الآمن
1. أوقف الباك إند؛ على الفرع الجديد شغّل `cd backend && npm run test:orders` (يتوقع 18 فحصاً، قاعدة بيانات مؤقتة).
2. شغّل `npm run test:settings` لتأكيد عدم تراجع نظام الإعدادات، ثم `cd ../frontend && npm run build` للتأكد من TypeScript.
3. **بعد نجاح الفحوصات فقط** خذ نسخة SQLite احتياطية صحيحة تتضمن `backend/prisma/dev.db` وملفات `backend/uploads`. راجع سلامة النسخة والأعداد.
4. أوقف الباك إند ثم شغّل `npm run db:push` من `backend`. إذا ظهر Data loss أو Reset **ارفض** وأوقف التفعيل.
5. شغّل الباك إند والفرونت إند؛ غيّر عنوان البنر أولاً من الإعدادات وراجع المعاينة واحفظ. تحقّق من أثرها على `/` وشاشة موبايل 390px.
6. جرّب رفع صورة مبدئية آمنة إن متوفرة، ثم إزالتها (ترجع للخلفية الزرقاء).

## ملاحظة تشغيلية
ميزة رفع الصور بالمشروع حالياً ترجع عنواناً محلياً `http://localhost:4000/uploads/...`؛ عند تجهيز نشر حقيقي يلزم استبدال مسار الرفع بعناوين عامة آمنة وتثبيت تخزين دائم للصور. **لا تُستخدم الروابط المحلية في الإنتاج.**

## مشكلة ثانية عولجت
داخل «حسابي» صارت قيم البريد والموبايل المكتوبة LTR تُحاذى إلى **يمين عمودها** بدل ما تبتعد إلى اليسار عن أسماء الحقول.
