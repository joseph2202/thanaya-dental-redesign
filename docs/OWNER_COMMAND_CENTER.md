# ثنايا — مركز قيادة المالك

> **مسودة تجربة إدارية مرئية** على فرع `feature/owner-command-center`، تحتاج بناء وفرز بصري على الماك قبل أي دمج. لا تغييرات Prisma أو API أو بيانات فعلية.

## الشاشة
المسار: `/admin`، للمستخدم `owner` أو `admin`.

بدلاً من أربع بطاقات وروابط فقط، الصفحة تعرض:
- ترويسة مركز القيادة مع زر **تحديث الآن** وتوقيت آخر تحديث حقيقي.
- نطاق زمني قابل للتغيير: **7 أو 30 أو 90 يوماً أو كل الفترة**.
- مؤشرات **الطلبات التي تحتاج متابعة (جديد + مؤكد + بالطريق)**، **قيمة الطلبات المسلّمة**، **عدد الطلبات ضمن الفترة**، **عدد المنتجات المسجلة**.
- مخطط قيمة الطلبات المُسلّمة في آخر 7 أو 30 يوماً مع حالة واضحة لو ماكو مبيعات.
- مراحل الطلبات الست مع الأعداد وشريط نسبة من مجموع الطلبات ضمن الفترة.
- آخر 5 طلبات من API الإدارة، مع الاسم والحالة والمبلغ ورابط شاشة الطلبات.
- تنبيهات نقص المخزون وصفر المخزون، مع اختصارات أعمال يومية.
- تحديث خفيف كل دقيقة أثناء مشاهدة التبويب، وعند الرجوع إليه، مع زر تحديث يدوي.

## السلامة والدقة
- تعيد استخدام `GET /api/reports/overview` و`GET /api/orders/manage`، **قراءة فقط**.
- لا تغيّر الكميات أو الحالات أو المال إطلاقاً.
- الحساب المحاسبي الحالي هو **قيمة الطلبات التي حالتها الآن مُسلّم**، وليس صافي ربح أو دليلاً على تحصيل النقد؛ مذكور في الواجهة.
- مؤشرات المخزون تشمل المسجل والمخفي؛ ليست بديلاً عن فحص صلاحية التشغيلات.
- إذا ماكو طلبات مُسلّمة تظهر رسالة بدل رسم وهمي.
- موظف المخزون والمبيعات يبقى فقط في صفحات الصلاحيات المتاحة لحسابه.
- تبديل الفترة يعيد جلب البيانات من السيرفر، ولا يخزن التقرير كحقيقة جديدة.

## الاختبار
1. بناء الواجهة: `cd frontend && npm run build`.
2. فتح `http://localhost:3000/admin` بحساب المالك، والتأكد من تناسق الأرقام مع `/admin/reports`.
3. تجربة تغيير النطاق، التحديث اليدوي، روابط التنقل.
4. راجع موبايل 390px وسطح مكتب 1440px، خصوصاً مخطط 30 يوماً والبطاقات.
5. جرّب موظف `sales` أو `inventory` بدون إعطائه صلاحيات تقرير المالك.
6. لا تستخدم مخزون/طلبات `test` في عرض للمالك وكأنها بضائع حقيقية.

## مراحل لاحقة (غير منفّذة بهذه الدفعة)
- إنشاء فاتورة طلب PDF / طباعة آمنة.
- تكلفة الشراء والهوامش وصافي الربح الحقيقي.
- مرتجعات جزئية، سجلات إثبات التحصيل، وتصدير Excel.
- تنبيهات انتهاء الصلاحية مع تواريخ وأسباب واضحة.
- تفاصيل التوصيل والمندوبين والشفتات وواتساب عند قرار صاحب المتجر.
- تحسين الموبايل الشامل واختبارات النهاية-إلى-النهاية؛ النشر آخر خطوة.
