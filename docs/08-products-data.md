# بيانات المنتجات

حالياً المنتج يحتوي على:

- اسم المنتج
- الوصف
- السعر
- الصور
- التصنيف
- الماركة
- الكمية / المخزون
- حالة التوفر
- هل هو منتج طبي؟ "اختياري أو لاحقاً"
- ملاحظات طبية "لاحقاً"
- ينصح باستخدامه من قبل مختصين "لاحقاً"

ملاحظة:
حالياً لا نحتاج وصفة طبية، فقط وصف عادي للمنتج مع صورة واسم وسعر.
