# Payment Provider Adapter — حد التنفيذ

الدفعة 8 تنفذ العقد والمحوّل التجريبي واختبارات البروتوكول. لا تسجل أي تحصيل ولا تعدل Checkout الإنتاجي ولا تطبق مخططاً. واجهة المحاكي والحفظ الدائم المعزول هي الدفعة التالية، ولم تعد مكتملة لمجرد وجود interface.

## العقد
- السيرفر يمرر orderId وamountIqd وIQD من snapshot محفوظ. لا يمرر المتصفح مبلغاً معتمداً ولا حالة paid.
- createPayment بمعرّف UUID ثابت للمحاولة؛ تبديل محتواه بنفس المعرّف يرفض. queryPayment يعيد دليل حالة موثّقاً، وrefund له معرّف مستقل ثابت ومجموع تراكمي محدود.
- pending / authorized / paid / failed / cancelled / refunded منفصلة. authorized ليست تحصيلاً. refunded قد تكون جزئية ويحدد المجموع مقدارها. failed/cancelled نهائية لهذه المحاولة، وإعادة المحاولة لها معرّف جديد.
- مقارنة provider/environment/reference/order/currency/amount قبل قبول الدليل. التسلسل يمنع التراجع وإعادة الكتابة. دليل متعارض أو انتقال غير مسموح يحتاج مراجعة، ولا ينفذ بضاعة أو تحصيلاً تلقائياً.
- adapters الحقيقية قد تختلف بتوقيعها وترتيبها؛ sequence هنا يجب أن تطبّعه من استعلام موثّق، ولا يفترض وجود رقم sequence لدى كل مزود.

## المحاكي
HMAC-SHA256 على timestamp + نقطة + bytes الأصلية، مقارنة ثابتة الزمن ونافذة 300 ثانية، حجم 8KiB وحدود حقول صريحة. هذا بروتوكول ثنايا للمحاكي؛ ليس تطبيق توقيع Qi/FIB/ZainCash.

MockPaymentProvider يأخذ repository بعقد createIfAbsent وCAS. اختبارات البروتوكول تستعمل ذاكرة مؤقتة صراحة؛ ليست إثباتاً على الحفظ بعد إعادة تشغيل السيرفر. دفعة الحفظ التالية يجب أن تثبت unique keys وtransaction وrestart بقاعدة SQLite مؤقتة، وevent receipt دائم لمنع إعادة الإشعار.

لا hosted URL وهمية: المحاكي يرجع null ويعلن hostedCheckout=false. لا PAN/CVV/expiry/token أو حقول إضافية في بيانات المزود الطبيعية. لا raw webhook في logs أو DB. لا شبكة خارجية أو حساب مالي.

## ما يلزم قبل أي تفعيل
المحاكي لا يتصل أبداً بسجل OrderPaymentEvent الحقيقي. واجهته القادمة owner-only وفي Preview مؤقتة مع حارس مسار وبيئة وعلامة عزل، وتعطيل قاطع في production. التكامل الفعلي يحتاج سجلاً منفصلاً للمدفوعات الإلكترونية، قيود مجموع التحصيل مع COD، وفشل/تأخر/تسوية/مرتجع وعقد مزود معتمد. لا يعد mock بديلاً عن ذلك.

التحقق: backend: `npm run test:payment-provider` (بناء + 11 فحص بروتوكول بلا قاعدة بيانات). CI يشغلها بعد بناء backend. لا مخطط مطلوب في هذه الدفعة.
