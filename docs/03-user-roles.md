# أدوار المستخدمين والصلاحيات

الأدوار المقترحة حالياً:

- مالك النظام / أدمن عام
- مدير
- موظف مبيعات
- موظف مخزون
- موظف دعم
- مسوّق
- مسؤول محتوى
- مسؤول طلبات
- بائع معتمد لاحقاً

مبدأ الصلاحيات:

- كل موظف يرى ويعدل فقط حسب وظيفته.
- الإعدادات الحساسة تكون للأدمن فقط.
- البائع المعتمد لاحقاً يدير منتجاته وطلباته فقط.
