# معاينة ثنايا RC1 على Mac — نسخة مستقلة

هذه معاينة إنتاجية من Next/Express وقاعدة صناعية؛ لا تحتاج .env أو مفاتيح المتجر ولا تقرأ dev.db الأصلية. احتفظ بمشروعك الحالي كما هو.

## التشغيل
تحقق من node --version (الحد الأدنى 22.13؛ الفحوص الأساسية على Node 22، وتشغيل Work الحالي على Node 24.22.1). افتح Terminal جديداً:

```bash
cd ~/Documents
git clone --branch release/rc1-schema-rehearsal-20261106 https://github.com/joseph2202/thanaya-dental-redesign.git thanaya-rc-preview-20261106
cd thanaya-rc-preview-20261106
bash scripts/preview-local.sh
```

إذا كان المجلد موجوداً فلا تحذفه: استخدم اسماً جديداً للنسخة. السكربت يرفض نسخة تحتوي backend/.env أو backend/prisma/dev.db، ويرفض المنافذ المشغولة دون قتل خادم آخر. يثبت اعتماديات lockfile، ينشئ SQLite/uploads تحت OS temp، ويبني production ويشغل Backend 127.0.0.1:4108 وFrontend 127.0.0.1:3108. كلاهما loopback، ولا Cloudflare/Tunnel.

افتح http://127.0.0.1:3108 للمتجر، وhttp://127.0.0.1:3108/login للدخول، ثم /admin للإدارة. البريد preview-owner@thanaya.local؛ كلمة مرور عشوائية مؤقتة تطبع في Terminal بعد seed. ليست كلمة مرور متجرك، ولا تحفظ في المستودع. يظهر شريط «معاينة خاصة — بيانات صناعية فقط».

جرب المنتجات/البحث/السلة، أنشئ حساباً صناعياً، ونفذ COD صناعية. المالية والمشتريات والطلبات الأولية كلها أمثلة وليست أرقام متجرك. أي شراء أو تعديل هنا يبقى في DB المؤقتة. Ctrl+C يوقف الخادمين ويحذف البيانات المؤقتة؛ أعد التشغيل لبداية نظيفة.

الموبايل: استخدم Responsive Design Mode في متصفح Mac لعرض 390px/320px. iPhone الحقيقي لا يصل إلى loopback الماك؛ لا نفتح شبكة أو صلاحيات إدارية عامة لتحقيق ذلك. اختبار WebKit/الهاتف يؤدى أيضاً ببيئة QA المعزولة.

## خيارات المطور
--skip-install يتجاوز npm ci عند وجود الاعتماديات المثبتة، --dev يشغل Next dev بدلاً من production، و--no-open يمنع فتح نافذة تلقائياً. استخدم الإعداد الافتراضي لمراجعة RC. لا تنقل .env أو dev.db أو uploads الأصلية إلى نسخة المعاينة.

## لماذا لا يوجد رابط Work عام؟
المنافذ محلية داخل بيئة التنفيذ؛ localhost في جهاز يوسف أو متصفح Work ليس عنوان خادم هذه الجلسة. لا ننشر admin أو بياناتها على رابط عام. private-preview-qa.cjs يشغل نفس launcher والخادمين والمتصفح معاً داخل CI ويلتقط صوراً حقيقية؛ ويعمل --http-only محلياً عندما يكون Chrome مقيداً، دون الادعاء باختبار متصفح.

## الحالة الحالية
فحص HTTP حقيقي لنسخة production نجح: owner/customer login، منع تعديل السعر للزبون، إنشاء/تعديل منتج، quote من السيرفر، طلب COD مكرر يعيد نفس ID ويخصم قطعة مرة واحدة وتحصيله صفر، ومؤشرات صناعية متطابقة (تحصيل 60,000، مصروف 25,000، مورد 348,000 وذمم 145,000). أثبت التنظيف حذف DB المؤقتة. Chrome وصور المتجر/الإدارة والشراء نجحت في #78/CI #262 وقُرئت. الفرع هنا يتضمن تقرير المرتجعات الجديد؛ تحقق من CI الخاصة به قبل اعتباره RC معتمدة.

لا تشغل الفرع على قاعدة متجرك الفعلية قبل إغلاق خطة Schema ونتيجة preflight/backup/rehearsal المحلية ثم موافقتك الصريحة. المعاينة الصناعية تعمل دون انتظار هذا التفعيل.

خطة فحص وتكوين نسخة احتياطية واستعادة وبروفة clone-only للمخطط الكامل في [RC_SCHEMA_PLAN.md](RC_SCHEMA_PLAN.md). لا تفعّلها على قاعدة المتجر؛ أوامرها لا تكتب إلى source.
