1. تعديل أصغر وحدة ممكنة، مع اختبارات إضافية على قواعد SQLite مؤقتة فقط، وفحص GitHub Actions.
2. عدم تغيير `backend/prisma/schema.prisma` أو تشغيل `prisma db push` على قاعدة المستخدم ضمن جلسة تقوية الأمان.
