## سياسة العمل الأمني

1. تعديل أصغر وحدة ممكنة، مع اختبارات إضافية على قواعد SQLite مؤقتة فقط، وفحص GitHub Actions.
2. عدم تغيير `backend/prisma/schema.prisma` أو تشغيل `prisma db push` على قاعدة المستخدم ضمن جلسة تقوية الأمان.
3. لا تقلب `paymentMethod` إلى بطاقة حقيقية؛ لا بيانات PAN/CVV، لا تأكيد دفع بلا webhook موثوق.
4. القضايا المفتوحة: JWT محفوظ في `localStorage` حالياً (خطر XSS)، تحديد محاولات الدخول in-memory (غير موزع)، ملفات الرفع، CSP/HTTPS، التحقق من IDOR، الفحص على بيئة خاصة، واختبار النسخ الاحتياطية.
5. حذف النصوص التقنية من واجهات الزبائن فقط؛ إبقاء حالات الدفع الصحيحة والتنبيهات القانونية غير المعتمدة وعدم تقديم ضمان أمان أو امتثال غير مثبت.
