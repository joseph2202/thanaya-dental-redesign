# ثنايا — نسخة إعادة التصميم المستقلة

هذه نسخة عمل مستقلة من مشروع `thanaya-dental`، محفوظة في مستودع `joseph2202/thanaya-dental-redesign`. تضم الواجهة والباك إند وملفات التصميم والوثائق، مع إعادة تصميم واجهات المتجر والإدارة. المشروع الأصلي في مستودع منفصل.

قاعدة SQLite المحلية (`backend/prisma/dev.db`) وملف `backend/.env` والصور المرفوعة في `backend/uploads` مستثناة من GitHub. تبقى البيانات الموجودة على جهازك كما هي، لكن نسخة جديدة من المستودع تبدأ بقاعدة فارغة حتى تضيف منتجاتك وبياناتك.

## ما تغيّر

- هوية بصرية جديدة بدرجات الأزرق الداكن والأبيض مع لمسات تركوازية، وتخطيط متجاوب للواجهة الرئيسية والهيدر والفوتر والتصنيفات والمنتجات وصفحة المنتج.
- رموز أقسام موحّدة، رسم توضيحي محلي للواجهة الأولى، وشعار SVG جديد مع إبقاء صور الشعار الأصلية ضمن المشروع.
- منتجات الصفحة الرئيسية ونتائج البحث تُجلب من API المتجر نفسه بدل بيانات الملف الثابت. تظهر صور المنتجات المرفوعة عند وجودها، وتُستخدم أيقونة كبديل عند غياب الصورة.
- صفحة العروض تعرض حالة صادقة عند غياب عروض فعلية بدل أسعار وخصومات تجريبية.
- إصلاح أخطاء TypeScript التي كانت تمنع بناء الواجهة في النسخة المرفوعة.
- ألوان ومظهر منسجم لبقية الصفحات ولوحة الإدارة؛ لم تتغير مسارات API أو بنية قاعدة البيانات.

## التشغيل على Mac عبر Terminal في VS Code

يتطلب المشروع Node.js مع npm. من مجلد المشروع، افتح Terminal أول للباك إند. الخطوات التالية تخص النسخة التي تنزلها من GitHub لأول مرة؛ إذا كانت نسختك المحلية تعمل، احتفظ بملف `.env` وقاعدة بياناتها ولا تستبدلهما:

```bash
cd backend
npm ci
cp .env.example .env
```

افتح `backend/.env` في VS Code وضع القيمتين التاليتين، مع مفتاح عشوائي خاص بك بدل النص التوضيحي:

```dotenv
DATABASE_URL="file:./dev.db"
JWT_SECRET="ضع_هنا_مفتاحاً_عشوائياً_طويلاً"
```

يمكن توليد مفتاح في Terminal بالأمر `openssl rand -hex 32` ثم نسخه إلى `JWT_SECRET`. بعد حفظ الملف، أنشئ قاعدة فارغة وطبّق مخطط Prisma. أمر `touch` لا يمسح بيانات ملف موجود، لكن لا تشغّل `db:push` على قاعدة فيها بيانات مهمة دون نسخة احتياطية ومراجعة أي تغيير في المخطط:

```bash
touch prisma/dev.db
npm run db:push
npm run dev
```

افتح Terminal ثاني من مجلد النسخة الرئيسي، ثم:

```bash
cd frontend
npm ci
npm run dev
```

افتح `http://localhost:3000`. الواجهة تتصل بالباك إند على `http://localhost:4000`، لذلك اترك نافذتي Terminal تعملان. القاعدة الجديدة لا تحتوي منتجات أو حسابات؛ أضف بياناتك الفعلية من خلال المشروع. إذا أردت فحص البناء بدل وضع التطوير، شغّل `npm run build` داخل كل من `backend` و`frontend` بعد تثبيت الحزم.

## دخول الإدارة

عمليات إدارة المنتجات والتصنيفات والكوبونات والطلبات والمستخدمين ورفع الصور تتطلب رمز دخول أدمن. `JWT_SECRET` مطلوب لتشغيل الباك إند. إذا كنت مسجلاً الدخول قبل تفعيل هذه الحماية، سجّل الخروج ثم ادخل مجدداً لتحصل على رمز صالح بالمفتاح الموجود في `.env`. تصفح المنتجات وإنشاء الطلبات الحاليان يبقيان متاحين كما كانا.

## حدود النسخة الحالية

ما زالت توجد مسائل تحتاج مرحلة مستقلة قبل إطلاق متجر عام: التحقق من بيانات الطلبات وحساب السعر والمخزون في الخادم، وربط سجل طلبات الحساب بقاعدة البيانات، ومراجعة حماية التسجيل وتخزين جلسة الدخول. لم يُجهّز هذا المشروع بعد لنشر خدمة عامة. احتفظ بنسخة خاصة من قاعدة بياناتك وصور المنتجات، لأن GitHub لا يخزنهما في هذا المستودع.
