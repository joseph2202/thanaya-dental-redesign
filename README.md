# ثنايا — نسخة إعادة التصميم المستقلة

هذه نسخة عمل مستقلة من مشروع `thanaya-dental`. لم تُنشر ولم تُرفع إلى GitHub. تضم الواجهة والباك إند وقاعدة SQLite المحلية والملفات والوثائق الموجودة في المشروع، مع إعادة تصميم واجهات المتجر والإدارة.

## ما تغيّر

- هوية بصرية جديدة بدرجات الأزرق الداكن والأبيض مع لمسات تركوازية، وتخطيط متجاوب للواجهة الرئيسية والهيدر والفوتر والتصنيفات والمنتجات وصفحة المنتج.
- رموز أقسام موحّدة، رسم توضيحي محلي للواجهة الأولى، وشعار SVG جديد مع إبقاء صور الشعار الأصلية ضمن المشروع.
- منتجات الصفحة الرئيسية ونتائج البحث تُجلب من API المتجر نفسه بدل بيانات الملف الثابت. تظهر صور المنتجات المرفوعة عند وجودها، وتُستخدم أيقونة كبديل عند غياب الصورة.
- صفحة العروض تعرض حالة صادقة عند غياب عروض فعلية بدل أسعار وخصومات تجريبية.
- إصلاح أخطاء TypeScript التي كانت تمنع بناء الواجهة في النسخة المرفوعة.
- ألوان ومظهر منسجم لبقية الصفحات ولوحة الإدارة؛ لم تتغير مسارات API أو بنية قاعدة البيانات.

## التشغيل على Mac عبر Terminal في VS Code

يتطلب المشروع Node.js مع npm. من مجلد هذه النسخة، افتح Terminal أول للباك إند:

```bash
cd backend
npm ci
cp .env.example .env
```

افتح `backend/.env` في VS Code وضع القيمتين التاليتين، مع مفتاح عشوائي خاص بك بدل النص التوضيحي:

```dotenv
DATABASE_URL="file:./dev.db"
JWT_SECRET="ضع_هنا_مفتاحاً_عشوائياً_طويلاً"
```

يمكن توليد مفتاح في Terminal بالأمر `openssl rand -hex 32` ثم نسخه إلى `JWT_SECRET`. بعد حفظ الملف:

```bash
npx prisma generate
npm run dev
```

افتح Terminal ثاني من مجلد النسخة الرئيسي، ثم:

```bash
cd frontend
npm ci
npm run dev
```

افتح `http://localhost:3000`. الواجهة تتصل بالباك إند على `http://localhost:4000`، لذلك اترك نافذتي Terminal تعملان. قاعدة البيانات المحلية الحالية `backend/prisma/dev.db` مرفقة، ولا تحتاج إلى تشغيل ترحيل عند أول معاينة. إذا أردت فحص البناء بدل وضع التطوير، شغّل `npm run build` داخل كل من `backend` و`frontend` بعد تثبيت الحزم.

## حدود النسخة الحالية

التصميم لا يغيّر طريقة تسجيل الدخول أو صلاحيات API أو معالجة الطلبات. ما زالت توجد مسائل في المشروع الأصلي تحتاج مرحلة مستقلة قبل إطلاق متجر عام: التحقق من صلاحيات الإدارة في الخادم، حساب السعر والمخزون في الخادم، وربط سجل طلبات الحساب بقاعدة البيانات. ملف SQLite المرفق يحوي بيانات تطوير؛ لا ترفعه إلى مستودع عام جديد.
